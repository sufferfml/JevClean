# 隐私说明

JevClean 在用户本机运行，通过 IMAP 操作原有邮箱，并直接调用用户账户的 Jev。项目没有云端服务、账户系统、遥测或密钥代理。

## 数据会去哪里

| 数据 | 位置与用途 |
| --- | --- |
| 邮箱密码／授权码 | 本机加密保存，连接时提交给配置的邮箱服务器 |
| Jev API key | 本机加密保存，调用时发送到 Jev 官方 HTTPS 接口 |
| 规则文字 | 本机加密保存，并与必要邮件文字一起交给 Jev 判断 |
| 规则动作及移动目标 | 本机加密保存，由程序执行；不作为动作字段或目标字段提交给 Jev |
| 主题、发件人地址、收件时间、状态、正文文字 | 从邮箱获取并用于 Jev 判断，必要字段会离开本机 |
| 附件与远程图片 | 不下载，也不发送给 Jev |
| 正文 | 默认只在运行内存和预览中处理，不写入基本报告或日志；主动开启完整调用记录后，实际发送的文字进入独立加密记录 |
| 主题、发件人、规则和问题快照、判断结果、原始选项及概率、恢复位置 | 本机加密的最近报告与最近操作凭据；基本快照不含正文上下文 |
| 调用状态、时间、HTTP 状态与已知用量 | 基本分析记录；缺失用量为未知，不视作零消耗 |
| 完整请求与各次服务响应 | 默认关闭；开启后在本机单独加密，密钥及认证头不进入记录 |
| 操作日志 | 本机明文的事件和汇总数字，不含上述邮件内容或凭据 |

可识别的口令／验证码、链接路径及内嵌 base64 图片数据会尽量隐藏，不能保证自动移除所有敏感信息。发件人地址和用户自然语言规则会提供给模型，以支持通用判断；如果不希望某些邮件文字离开本机，应选择其他文件夹或停止分析。

Jev 的保留和处理政策由服务商决定，详见 [TypeSafe 官方文档](https://docs.typesafe.ai/models#data-handling) 和 [法律说明](https://docs.typesafe.ai/legal)。JevClean 不宣称完全离线或第三方零保留。

完整调用记录只包含开启之后实际发送和收到的数据，不能补回旧请求；服务响应可能回显个人信息。仅保留最新分析批次、最长 7 天、总量最多 50 MiB，单次响应最多 1 MiB；截断明确标识且不用于判断授权。应用启动和访问时清理到期数据，应用关闭期间到期的数据在下次启动时清理。容量或保存失败会停止分析，不会静默丢弃记录再继续调用。

## 本地保护

AES-256-GCM 加密配置和记录，解密钥匙存 macOS 钥匙串、Windows 系统凭据库或 Linux Secret Service。没有明文或临时内存密钥降级。用户填写时密钥短暂存在页面输入框和本地 API 请求中，保存成功后清空；页面不能读回已存密钥，也不将它们写入 localStorage／sessionStorage。sessionStorage 只保存本地会话令牌。

本地 HTTP 只监听回环地址，具名 API 需要随机令牌，并校验 Host／Origin；不向其他网页开放 CORS。该程序不适合开放端口提供远程使用。同一系统用户或高权限本机程序仍可能访问正在运行的进程；它不是防御已被控制电脑的隔离环境。

## 清理与删除本地数据

分析只读，不修改位置、已读或星标。选中并确认后执行规则保存的动作：删除移到邮箱垃圾箱，归档／移动／垃圾邮件移到确认的目标，标记动作只改对应标记。应用不执行永久删除，不自动清空垃圾箱；垃圾箱中邮件的保存期限由邮箱服务商决定。移动需 MOVE／UIDPLUS；标记操作保存原始值以供撤销。旧 JevClean 待清理文件夹的移动仍可用旧凭据恢复。

「核对操作结果」以及缺少确认后的自动核对，只读相关文件夹的邮件编号、邮件头、收件时间和标记，在本机比对身份并更新加密操作记录；不读取正文、不调用 Jev、不修改邮件。核对汇总和时间随最近操作保存。动作冲突选择只更新本机报告，不操作邮箱；日志不记主题、路径或原始邮件内容。

「清除本地凭据」从加密配置中去掉邮箱密码和 Jev key；系统凭据库中的随机数据解密钥匙继续保护规则和恢复记录。关闭「保存原文」并保存设置，或点击「清除原文」，只删除独立调用记录，保留基本判断和撤销凭据。「清除分析记录」则删除报告、完整调用记录及恢复凭据，不操作服务器上的邮件，之后不能通过应用撤销。

数据目录：

- macOS：`~/Library/Application Support/JevClean`
- Windows：`%APPDATA%/JevClean`
- Linux：`${XDG_DATA_HOME:-~/.local/share}/JevClean`

需要彻底移除时先退出，再删除该目录，并在系统凭据库删除 `org.jevclean.local-vault` 对应条目。不可只删除钥匙再继续使用原加密文件；程序会拒绝覆盖，以免丢失恢复凭据。旧版本凭据不会自动迁移。

操作诊断在本机运行日志中仅保存固定原因代码、汇总数量和核对耗时，帮助区分移动确认缺失、连接或响应异常、核对读取失败及最终位置不明确。不记录邮件标识、主题、地址、文件夹、协议原文或密钥，沿用日志轮换和条数限制。
