# JevClean 使用说明

JevClean 直接连接现有邮箱，Apple Mail、飞书客户端和网页邮箱会同步看到移动结果。对于仍由飞书管理的自定义域名邮箱，选择飞书 IMAP 服务器即可，不需要修改域名或迁移到 Gmail。

整理后可能需要自动核对邮箱中的实际结果。此时相关邮件显示「核对中」，已确认成功的邮件保持成功状态；请等待核对完成，无需手动刷新。只有核对结束仍无法确认的邮件才显示黄色原因和「核对结果」，这些邮件仍不能重复处理。核对仅查询位置或标记，不再次删除邮件，也不调用 Jev。

分析结束后，顶部显示「分析完成」和本次邮件数量；整理全部确认成功后显示「整理完成」及处理数量。完成提示不会在5秒后自动消失，可以手动关闭，下一项操作会清除。停止、中断、未获得有效判断或部分整理未成功时，提示会说明实际结果和数量。页面刷新后仍在进行的任务，结束时也会显示提示；打开历史结果不会重复弹出完成提示。

## 日常怎么用

分别在设置中的「分析服务」「邮箱设置」「显示语言」完成配置后，回到工作区，在左侧依次设置「选文件夹」「邮件范围」「整理规则」，再点击「开始分析」。结果分为「符合规则」「待查看」「暂不整理」「全部邮件」。命中邮件中可执行的项目默认勾选；取消不想处理的邮件，点击「整理」，在弹窗中核对数量、动作和去向后确认执行。

邮件区上方始终显示手动操作按钮。任何分类中都可勾选已加载、位置已确认的邮件，自行选择删除、移动、归档、垃圾邮件或标记操作。分析只给出判断；按规则整理与手动操作都要明确确认，才会修改邮箱。

## 准备与配置

双击 macOS 应用或按 README 从源码启动，浏览器自动打开本地界面。首次进入设置时默认打开「分析服务」，填写自己的 Jev API key；「邮箱设置」单独配置邮箱地址和密码／授权码，「显示语言」单独选择界面语言。已有完整配置则进入工作区。设置导航依次为「分析服务」「邮箱设置」「显示语言」「管理规则」「隐私记录」，右上角可切换「设置」和「返回邮件」。

「邮箱设置」页提供服务商预设和手动 IMAP 配置，保存后可测试连接。密钥保存成功后输入框清空，显示“已保存，无需重填。填写新值可替换。”；换邮箱账号或服务器不会沿用原账号密码。各页共享同一份配置和密钥草稿；切换页面或返回邮件保留尚未保存的内容，点击保存仍保存当前全部有效设置，开始分析前也会保存有效修改。

| 邮箱预设 | IMAP 服务器 | TLS 端口 | 需要准备 |
| --- | --- | --- | --- |
| Gmail | imap.gmail.com | 993 | 开启两步验证后生成应用专用密码，组织策略可能禁用 |
| QQ | imap.qq.com | 993 | 开启 IMAP，生成授权码 |
| 163 | imap.163.com | 993 | 开启 IMAP，生成客户端授权密码 |
| 126 | imap.126.com | 993 | 开启 IMAP，生成客户端授权密码 |
| iCloud | imap.mail.me.com | 993 | Apple 账户 App 专用密码 |
| 飞书 | imap.feishu.cn | 993 | 管理员允许第三方客户端，成员生成专用密码 |
| 其他 | 服务商给出的地址 | 服务商给出的 TLS 端口 | 对应客户端凭据 |

测试邮箱连接成功后显示约 5 秒的提示，可手动关闭。右上角显示「连接成功」，悬停可查看最近验证时间；它表示本次运行中这组账号与密码已成功验证，空闲时不保持 IMAP 长连接。重启后显示「待检查」，测试连接或开始分析会更新；换账号、服务器或密码后重新验证。

这些是连接预设，**不是各服务商已通过真实账号验收的声明**。测试连接确认认证及文件夹；实际移动还需要服务器支持 MOVE 和 UIDPLUS。只允许 OAuth、管理员禁用第三方访问或不提供专用密码的账号暂不支持，Outlook／Exchange 的 OAuth-only 账号亦如此。

飞书：[官方第三方客户端说明](https://www.feishu.cn/hc/en-US/articles/902478147400-log-in-to-feishu-mail-through-a-third-party-email-client)。管理员开启后，在飞书桌面客户端头像 → 设置 → 邮箱 → 第三方邮箱客户端登录中生成密码。这里配置的是个人邮箱，公共邮箱不是必需条件。

Gmail：[官方 IMAP 地址](https://developers.google.com/workspace/gmail/imap/imap-smtp)、[应用密码要求](https://support.google.com/accounts/answer/185833)。没有应用密码选项时检查组织限制或高级保护，当前应用没有“Google 登录”替代入口。输入应用密码时去掉显示用的分组空格。

网易：[授权与客户端说明](https://help.mail.126.com/faq.do?categoryID=90&m=list)。iCloud：[官方服务器设置](https://support.apple.com/en-us/102525)。QQ 以当前邮箱设置里的 IMAP 授权步骤为准。

## 规则

主界面左栏的「整理规则」直接显示每条规则的名称、动作和启用复选框。详细自然语言条件默认收起，点击该条规则内的「展开」查看全文，再点「收起」隐藏；每条独立控制，不改变规则勾选。勾选本次使用的规则，取消勾选后不提交该规则；没有任何启用规则时不能开始分析。侧栏和规则列表始终显示，内容多时滚动左栏；右侧邮件滚动不会带动左栏。

整理规则区仅保留「管理规则」入口，点击后可修改预设及自定义内容，也可在管理页点击「添加规则」填写名称、自然语言条件和一个动作；新规则排在最上面。设置页不重复启用复选框，主界面统一管理勾选。管理页的规则描述直接显示全文；名称只用于列表展示，实际判断以完整描述为准。预设也是可编辑文字，不是隐藏代码限制。无需填写运算符、字段或正则；切换页面保留未保存修改。

四条预设都按邮件的主要用途判断，附带的推荐、免责声明或通用按钮不自动改变分类。普通规则内的“保留／排除”只让本条规则不命中，不会阻止其他规则；需要跨规则保护时，另建一个动作设为「保留」的规则。例如广告规则排除简历，仍允许简历清理规则命中；若所有规则都不能处理发票，应单独建立保留发票的规则。


| 默认规则 | 清理范围 | 时间条件与本条规则的排除例外 |
| --- | --- | --- |
| 广告推广 | 商品、服务或品牌营销群发，包括厂商公开课／峰会的营销邀请 | 不要求过期；保留交易记录、报名凭证和正在进行的个人业务沟通，即使其中附带优惠 |
| 验证码 | 已失效的一次性登录、注册或身份验证代码，包括附带安全提醒的验证码邮件 | 按明确有效期／截止时间；未注明时超过 24 小时；保留恢复码、长期激活码及独立安全告警 |
| 过期活动 | 过期的活动介绍、推广、报名邀请和提醒 | 活动介绍看最后一场结束时间，仅用于报名的邀请看最终报名截止；时间不明不清理；保留门票、报名凭证、证书、个人安排和需要处理的变更通知 |
| 旧通知 | 旧点赞、关注、内容推荐和社交动态汇总 | 超过 30 天；保留真实私信、评论回复、提及、个人沟通及明确待办；“查看详情”不算待办。首次配置默认不启用 |

默认预设用于首次配置。已保存的规则描述、排序、勾选状态原样保留，不自动更新或补回删除的规则。修改启用规则后须重新分析；最近操作的恢复记录仍保留。

例如：

- 清理超过一个月的招聘推荐，但保留正在沟通的职位。
- 清理收到超过一个月的招聘推荐、简历投递邮件、新简历通知和简历汇总邮件。
- 清理营销群发，但保留我已经回复或标星的邮件。
- 清理已结束的培训推广，保留报名成功、付款凭证和课程资料。

描述需要覆盖实际想处理的邮件形式。例如只写“简历”，未必明确包含平台发来的“新简历通知”和“简历汇总”；需要处理它们时，应一起写进条件。时间要求也要说明是收到多久，还是邮件内的活动何时结束。名称用于概括，不会替描述补全这些边界。

可明确写时间要求和本条规则的排除例外。未保存的修改会在开始分析时自动保存，也能立即保存。修改已开启规则后，旧结果暂停按规则处理，需要重新分类；同一邮箱仍可手动处理。相同发件人的每封邮件单独判断；界面显示动作及符合规则，没有任何完整命中时不执行，普通规则的不确定不阻止其他完整命中。

## 动作与文件夹

每条规则选择一个「处理方式」动作：删除、归档、移动、标为垃圾邮件、标记已读／未读、添加／取消星标或保留。预设及旧规则缺少动作时默认删除，但只有重新分析、勾选并确认后执行；旧移动的撤销记录保留。自然语言描述仍决定条件、时间与排除例外。

选择移动时必须选目标文件夹；点击「刷新列表」获取列表。删除、归档和垃圾邮件优先使用你指定的目标，其次读取服务器用途标识，再识别唯一的常见名称，例如「已删除」「废纸篓」。多个候选不自动选一个，也不创建文件夹。无法确认时会进入「设置 → 管理规则」顶部检查区，选择存放文件夹或调整规则，保存并检查通过后返回邮件；设置中的「存放位置」也可修改。垃圾箱指邮箱里用于放置删除邮件的文件夹，不是本机废纸篓。Gmail 使用 All Mail 归档只接受 INBOX 来源；其他标签可用移动动作。删除移入垃圾箱，应用不会清空垃圾箱；邮箱服务商可能按自己的保存期限清空。垃圾邮件动作移动到 Junk，不承诺训练服务商的反垃圾模型。

## 开始分析，再整理邮件

左栏常驻显示文件夹、分析范围、整理规则和发送许可，底部常驻「开始分析」。可查找并勾选一个或多个文件夹，默认 INBOX；选择最近 X 封或全部邮件。最近 X 封按所选文件夹合计、服务器收件时间排序。窄窗口仍保留左栏与右侧邮件区，可横向访问完整工作区；不自动隐藏配置。

同意发送必要的邮件文字后，点击「开始分析」会在内部完成读取并调用 Jev。**分析针对所选文件夹和数量范围，不是当前勾选的邮件。** 界面不再要求单独读取邮件。范围外邮件不读取正文、不交给 Jev；分析不会改变已读状态或移动邮件。每次分析可能再次消耗 Jev 额度；符合条件的失败请求可单独重试，但这不等于增量分析或恢复整个未读完的范围。

开始前先自动检查全部启用规则的目标和服务器能力，失败停在正文读取与 Jev 调用之前，并打开规则设置中的修复区。预检只读，不保证之后网络或权限不变。邮件区只保留例如「删除后移到「已删除」」的去向提示，修改或重查在规则设置中完成。分析可停止，已完成结果保留。分析元信息只显示时间和 token 累计；这里只统计获得有效判断的响应用量，不能反映所有失败和中间重试的消耗，也不能当作完整账单。

结果始终按以下四类查看，邮件行分别显示 AI 判断和真实处理结果：

| 分类 | 包含什么 | 如何处理 |
| --- | --- | --- |
| 符合规则 | 已确定命中处理规则的邮件；处理完成也留在该分类 | 可执行项默认勾选，取消不需要的项目后点「整理」；也可手动指定动作 |
| 待查看 | 判断证据不足、全局保留条件不确定、请求失败、未分类及同级动作冲突 | 查看分析记录；符合条件的请求失败可重试，冲突可选已完整匹配动作，也可手动处理 |
| 暂不整理 | 全部普通规则明确不匹配，或命中独立全局保留规则的邮件 | 查看具体原因，需要时可手动处理 |
| 全部邮件 | 当前报告内所有邮件 | 可勾选并手动处理 |

多条普通规则完整命中时，处理优先级为：**删除 > 垃圾邮件 > 移动 > 归档 > 标记操作**。只在最高级别内比较：相同动作和目标合并，不同动作或目标仍待查看。例如删除与归档同时命中会取删除；移往两个不同文件夹、同时要求已读和未读，均需选择。独立保留规则完整命中时全局保护；无法明确排除该保留规则时也不放行其他规则动作。普通规则自己的例外或不确定不否决其他完整命中；没有完整命中绝不会因“没有保留理由”而清理。每封邮件只执行一个动作。

重新打开有效分析结果、分析结束或回到「符合规则」时，默认勾选当前可执行的命中邮件，可逐封取消。已完成、已撤销、无需重复操作、位置未知或缺少执行条件的邮件不会因默认勾选获得执行资格。切换到其他分类会清除选择和搜索，避免把上一分类的选择带入新动作。

「搜索邮件」只查已加载的主题／发件人，不搜索整个邮箱、不发送搜索词到云端。改变搜索词时，未匹配的邮件会取消勾选；清空搜索后不会自动补选。工具栏显示已选数量；通过邮件复选框或列表的全选控制调整选择，不另设「查看已选」「清除选择」按钮。点主题在列表下方打开纯文本阅读区，勾选与阅读互不影响；关闭或按 Escape 返回原邮件按钮及右侧滚动位置。正文按需从邮箱读取，不下载附件或远程图片。行内「分析记录」则独立读取本地证据，不需要重新连接邮箱。

邮件区上方常驻删除、移动、归档、标为垃圾、标为已读、标为未读、添加星标、取消星标八个手动按钮，以及固定名称「整理」。未选邮件时按钮禁用；「整理」只有在「符合规则」且当前结果有效、有可执行选中项时可用，其他分类显示灰色禁用。点击「整理」打开弹出式确认窗口，展示本次实际处理数量、动作和目标，之后明确确认才执行；不再重复列出「将按规则处理的邮件」，有排除项时仍保留数量和跳过原因。重复命中只处理一次；规则或范围改变后需重新分析才能按规则整理。

手动按钮可在任意分类使用，不受 AI 概率、保留判断或规则摘要限制，但仍核对账号、邮件身份和位置。手动移动自动读取文件夹列表；每次只指定一个动作，检查后列出准备处理、将跳过、暂不能处理的数量及逐封原因，再确认执行。修改目标会清空旧计划并要求重查；系统目标缺失时可单独保存位置，不会一并提交规则或密钥草稿。手动处理不调用 Jev、不改写原 AI 分类，例如保留邮件被手动删除后仍显示原判断及“手动处理：删除”。手动检查与确认也在弹窗中进行。弹窗打开时背景不可操作，初始焦点在「取消」；点击取消或按 Escape 返回原触发按钮。上一批结果未知时先核对，不允许重复处理。

「最近整理」显示真实处理进度和结果；正常完成收起详细时间，保留数量、去向、刷新和撤销；部分失败／未知结果自动展开，并只列最近一批的异常项，不混入其他报告或批次。上一批仍有结果未确认时，先刷新确认再处理下一批，避免覆盖恢复记录。批次去向取自那次操作记录，之后修改设置或重新分析不会把旧去向改成新位置。刷新页面可继续查看；重新分析或重启仍保留最近一次整理的撤销入口。标记撤销只恢复该操作涉及的标记，不覆盖其他标记。

缺少完整确认信息时自动只读核对一次，也可点击「核对结果」。移动操作核对原／目标文件夹中的唯一邮件身份及 UIDVALIDITY；标记操作核对原身份和原始／目标值。不读取正文、不调用 Jev、不重复执行。重复副本、未知原始标记、已变化的文件夹或位置无法确认时仍显示待核对，请在原客户端检查。

整理进入核对阶段时显示「核对中」，并保留本次整理的封数。下方显示当前文件夹的邮件列表检查进度，例如「200 / 1497 条」表示已检查 200 条邮件记录；这不是整理或 AI 分析的封数。切换文件夹时名称和检查进度一起更新。核对只查询邮件信息，不处理其他邮件或消耗 Jev 额度；完成后按实际结果显示已处理、未成功和结果待查的数量。

只修改垃圾箱、归档、垃圾邮件映射或移动目标时，已有 AI 判断继续保留；在「设置 → 管理规则」点击「保存检查」或「检查邮箱」，检查通过后返回邮件并恢复可执行状态，不重复消耗 Jev 额度。移动目标变化造成的动作冲突会重新合并或拆分，需要时重新选择动作。修改邮箱、规则条件、动作或分析范围后，按规则处理前需重新分类；规则变化不阻止同一邮箱的手动处理，不影响最近操作的核对与撤销。旧结果只在同一判断版本、原配置一致、原始匹配证据完整时恢复，证据不足的结果不会放行。本轮局部例外语义使用判断版本 8，v6／v7 等旧报告需要重新分析才能按规则整理；同账号的手动操作和最近批次撤销仍独立可用。

## 界面语言

在「设置 → 显示语言」选择中文或 English，界面立即预览；保存后下次打开沿用，默认中文。语言仅改变界面及应用提示，邮件主题、正文、文件夹名和用户规则保持原样，不额外调用 AI 翻译，也不改变 Jev 请求或已有分析的执行资格。

## 错误与退出

- API key 无效、额度不足或连续三次请求失败时停止分析；已完成结果仍可查看。
- 邮件正文过长／不完整、时间无法确认或模型把握不足时保留，不提供“强制清理”开关。
- 邮箱状态、账号或规则变动后，旧结果可能失效；按提示重新分析。
- 移动结果未能自动确认时显示「结果待查」，先点击「核对结果」；仍不确定时在原客户端核对，不重复移动。
- 系统凭据库不可用时无法保存，请解锁钥匙串；Linux 必须有 Secret Service。
- 浏览器提示会话失效时重新打开应用；正常运行实例会复用已有本地地址。

「设置 → 隐私记录」可查看简短隐私说明、展开数据处理详情和运行记录，并移除已保存的密码与密钥或清除分析结果和撤销记录。页面底部不再显示隐私文案或快捷按钮。右上角「应用菜单 → 退出应用」结束服务与启动器。任务执行期间按钮禁用，分析可先点「停止分析」，执行／撤销需等待完成。关闭浏览器标签页不会自动终止正在执行的任务，重新打开应用可继续查看进度。

规则名称只是概括，实际范围以可编辑的描述为准，例如「旧通知」预设覆盖旧点赞、关注、内容推荐与社交动态汇总，不代表所有旧邮件。版本 8 新提示与局部例外语义已实现，最终全量检查与安装结果待本轮单独记录；尚未进行真实 Jev 质量验证。

## 查看分析记录和重试失败邮件

点击邮件行的「分析记录」，可分别看到发送当时的规则、模型对条件和时间的原始回答／概率、程序为什么采用或拦截，以及每次调用的状态、耗时、HTTP 状态和已知 token 用量。概率不是准确率；没有收到用量的失败不能当成零消耗，详情会明确标出未知。只查看这些已保存证据不调用邮箱或 Jev，即使当前无法读取正文仍能检查记录。旧报告没保存的字段会显示缺失，不会用当前规则补成历史记录。

默认只保存基本分析证据，不保存正文上下文、完整请求或服务响应。需要核对实际提交的全部文字时，先在「设置 → 隐私记录」开启「保存原文」并保存，再进行之后的分析。完整记录含实际发送的文字和服务返回，可能有个人信息，在本机单独加密；仅最新批次、最长 7 天、最多 50 MiB，单次响应最多 1 MiB。超过响应上限会明确标注截断，该回答不会用来处理邮件。到期记录在启动或访问时清理，应用关闭期间到期的数据下次启动清理。关闭开关并保存、或点击「清除原文」，不影响基本判断和上次整理的撤销。

只有未获得有效判断、尚未执行并保存了新版输入摘要的邮件可「重试分析」，成功但把握不足的判断不能借此反复重跑。重试须保持同一账号、规则与范围，原分析不超过 7 天；程序只读重新核对邮件身份、文字和状态，实际输入改变时要求重新分析。旧尝试及失败说明保留，新的尝试追加显示。重试会再次调用 Jev 并可能消耗额度；它不会重复执行删除或移动。已执行结果未知时仍应使用「核对结果」核对邮件状态。

## 自动保存和菜单栏

左栏的文件夹、最近／全部范围和有效邮件数量，以及已保存规则的启用状态与发送同意项修改后自动加密保存，无需再点「保存修改」。连续勾选会合并保存；保存失败时保留选择，点「重新保存」。同意项会保留到下次打开，取消勾选后不能开始分析。取消全部文件夹或规则也会保存，但开始分析前至少选择一个文件夹和一条规则。设置页的邮箱、API、规则内容和语言可点该页保存按钮，也会在开始分析时完整保存有效修改。新规则第一次保存前的勾选保留在草稿中，不向分析偏好接口发送尚未保存的规则标识；切换偏好不会提前提交规则内容或密钥草稿。

macOS 运行时顶部显示信封图标。菜单提供运行状态、打开应用、重启应用、退出应用；状态和菜单跟随已保存的中文／英文语言。关闭页面后可从图标或双击应用重新打开，首次验证时不打开页面也不影响后续打开。任务进行中禁止重启和退出；先在网页停止分析，或等待整理／撤销完成。后台无响应时不会强制重启正在处理的邮件。退出后图标消失；重启和退出均保留已保存配置、分析结果和撤销记录。
